# 🍕 ODOD PIZZA

Веб-приложение для заказа пиццы с полноценной корзиной, системой промокодов, личным кабинетом, админ-панелью и интеграцией с искусственным интеллектом.

---

## 📋 О проекте

**ODOD PIZZA** — это учебный проект интернет-магазина пиццерии, написанный на чистом Python (стандартная библиотека) + SQLite + HTML/CSS/JS.

**Стек технологий:**
- 🐍 **Python 3** — бэкенд (стандартная библиотека `http.server`, `sqlite3`)
- 🗄 **SQLite** — база данных (один файл `ododpizza.db`)
- 🌐 **HTML5 + CSS3** — фронтенд
- ⚡ **JavaScript (vanilla)** — интерактивность
- 🤖 **Yandex AI Studio** — умные ответы на фидбек
- 📊 **draw.io** — ER-диаграмма базы данных

## 🤖 Подключение искусственного интеллекта (ИИ)

В проекте реализована функция **«✨ Предложить ответ с помощью ИИ»** для администратора. Чтобы она заработала, нужно создать файл с ключами.

> ⚠️ Файл с ключами (`.env`) **не загружается на GitHub** из соображений безопасности. Его нужно создать самостоятельно.

### Инструкция:

1. **Создай файл `.env`** в корне проекта (рядом с `server.py`). 
   *В Windows через Блокнот: «Файл → Сохранить как» → Тип файла: «Все файлы» → Имя: `.env` (с кавычками) → Кодировка: UTF-8.*

2. **Вставь в него три строки**:
```env
YA_API_KEY=твой_длинный_секретный_ключ
YA_FOLDER_ID=твой_id_каталога
YA_AGENT_ID=твой_id_агента
