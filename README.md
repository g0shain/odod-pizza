# 🍕 ODOD PIZZA

Веб-приложение для заказа пиццы с полноценной корзиной, системой промокодов, личным кабинетом и админ-панелью.

---

## 📋 О проекте

**ODOD PIZZA** — это учебный проект интернет-магазина пиццерии, написанный на чистом Python (стандартная библиотека) + SQLite + HTML/CSS/JS.

**Стек технологий:**
- 🐍 **Python 3** — бэкенд (стандартная библиотека `http.server`, `sqlite3`)
- 🗄 **SQLite** — база данных (один файл `ododpizza.db`)
- 🌐 **HTML5 + CSS3** — фронтенд
- ⚡ **JavaScript (vanilla)** — интерактивность
- 📊 **draw.io** — ER-диаграмма базы данных

**Никаких сторонних библиотек и фреймворков** — только Python из коробки.
